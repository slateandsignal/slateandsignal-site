Substack image sizes, from Substack's own official help documentation (checked 2026-08-11):

  Post header / cover image ... 1456 x 1048 px, 14:10 aspect ratio
  Publication logo ............ 256 x 256 px minimum, 1:1, transparent background
  Publication cover image ..... 600 x 600 px minimum, 1:1
  Publication banner/wordmark . 1344 x 256 px minimum, 21:4 maximum ratio

No official numbers exist for the author profile photo, Notes images, or a maximum
upload file size. Substack does not publish them.

Ignore the 1200x630 and 1456x816 figures that third-party guides repeat. Substack's
own docs say 1456 x 1048.

Blog heroes live in ../blog/ and are portrait (1280 x 1920). They are the wrong shape
for Substack. Cut a separate landscape version into this folder for every post.

Tags, checked 2026-08-11:

Substack DOES have post tags, and Notes DO take hashtags. An earlier note in this
project claimed otherwise and was wrong.

  Post tags ....... organizational, not a ranking factor. Each tag builds its own
                    tag page that can be added to the publication nav bar. No
                    documented maximum. Set at Settings > Website > Tags or in a
                    draft's settings. Reuse a small consistent set so the tag pages
                    accumulate.
  Notes hashtags .. genuinely aid discovery inside the Notes feed. The five-hashtag
                    cap applies here like everywhere else.

Publication categories and sections are separate again: categories describe the whole
publication, sections structure the homepage.
